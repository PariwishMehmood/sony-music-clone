# Sony Music Clone

A frontend website inspired by Sony Music's official website, developed as a web development project using HTML, CSS, and JavaScript.

## About the Project

This project recreates the general look and navigation of a music company's website. It provides multiple pages to explore artists, music-related news, videos, and company information.

This is an educational frontend project and is not an official Sony Music website.

## Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, layout, animations, and responsive design
- JavaScript — Interactive features and form validation

## Features

- Home page with a visual landing section
- Artists page displaying artist information
- News page for music-related updates
- Videos page featuring video content
- About page with company information
- Contact page with contact form functionality
- Navigation between pages
- Search and interactive elements
- Responsive styling for different screen sizes
